# Execution Prompt — Phase 1 UI Foundation dan Shell

## Instruksi
Baca `AGENTS.md`, `PRD.md`, `UI-GUIDELINE.md`, dan `IMPLEMENTATION_PLAN.md` terlebih dahulu. Implementasikan **Phase 1 saja** untuk aplikasi SPK Pemilihan Guru Terbaik Bimbingan Belajar Nurul Fikri.

## Target
- Siapkan proyek front-end React + Vite.
- Bangun fondasi visual sesuai UI Guideline: palet biru, tipografi, spacing, surface, border, radius, dan state dasar.
- Buat app shell responsif dengan sidebar/header.
- Tambahkan navigasi untuk enam modul sesuai nama di PRD.
- Buat Dashboard awal berisi ringkasan dan visualisasi sederhana menggunakan data simulasi yang diberi label jelas.
- Untuk modul selain Dashboard, cukup tampilkan halaman placeholder yang konsisten dan informatif; jangan implementasikan logika modul fase berikutnya.

## Batasan
- Jangan membuat backend, database, login nyata, API, atau integrasi eksternal.
- Jangan menambah modul di luar enam modul yang disetujui.
- Jangan mengubah kriteria, bobot, atau rumus SAW dalam dokumen.
- Gunakan dependensi sesedikit mungkin; jelaskan jika menambah dependensi.
- Jangan lanjut ke Phase 2.

## Validasi
- Jalankan pemeriksaan yang tersedia, termasuk build produksi.
- Periksa navigasi enam modul dan layout desktop/mobile.
- Jangan mengklaim validasi berhasil jika perintah tidak dijalankan.
- Catat masalah yang belum terselesaikan.

## Format Hasil
1. Ringkasan Phase 1.
2. Struktur file penting.
3. Cara menjalankan proyek.
4. Preview atau deskripsi tampilan.
5. Perintah validasi yang dijalankan beserta hasil.
6. Batasan yang tersisa.
7. Minta keputusan eksplisit: setuju lanjut Phase 2 atau minta revisi.

Berhenti setelah laporan Phase 1. Jangan mengerjakan fase berikutnya tanpa persetujuan baru.
